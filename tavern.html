Создание API-ключей и выбор группы

1

Перейдите в «Управление токенами»

В боковом меню консоли выберите «Управление токенами». По умолчанию у вас уже создан первый токен — это ваш API-ключ.

Для удобного переключения между группами можно создать несколько токенов.

2

Нажмите «Редактировать»

Рядом с нужным токеном нажмите «Редактировать».

3

Выберите группу токенов

При желании дайте токену понятное название. В поле «Группа токенов» выберите подходящую группу.

Без выбранной группы ключ работать не будет — платформа выдаст ошибку.
🍺

Подключение SillyTavern

Подключение через Chat Completion

Откройте настройки подключения в SillyTavern и заполните поля:

  • API — Chat Completion.
  • Источник для Chat Completion — Claude, а для Gemini — Google AI Studio.
  • Раскройте блок «Прокси».
Адрес прокси-сервера для Claude https://api.linkapi.ai/v1
Адрес прокси-сервера для Gemini — без /v1 https://api.linkapi.ai/

В поле «Пароль от прокси» вставьте свой API-ключ. Дополнительные эндпоинты указаны в Discord.

📋

Выбор модели

Обычно модели подтягиваются автоматически

Для обычных групп копировать названия моделей с сайта не нужно. После ввода API-ключа SillyTavern подтянет модели выбранной группы. Выберите нужную в выпадающем списке версий.

Если в списке есть варианты названия с цифрами и без цифр, выбирайте вариант с цифрами. Исключение — claude-opus-4-6.

Для группы Once порядок другой — он описан ниже.

⭐

Группа Once — через Custom Models

Для Once модель нужно добавить вручную

Модели группы Once не подтягиваются автоматически. Для их добавления используется расширение Custom Models для SillyTavern:

github.com/LenAnderson/SillyTavern-CustomModels ↗

1

Скопируйте название модели с сайта

Откройте раздел моделей на сайте LinkAPI, выберите группу Once, найдите нужную модель и скопируйте её название с помощью иконки рядом с ним.

2

Добавьте модель через расширение

Установите расширение и вставьте скопированное название в поле Custom Models.

Если расширение не работает, попробуйте сменить язык SillyTavern на английский.
