Создание API-ключей и выбор группы

1

Перейдите в «Управление токенами»

В боковом меню консоли выберите «Управление токенами». По умолчанию у вас уже создан первый токен — это ваш API-ключ.

Для удобного переключения между группами можно создать несколько токенов.

2

Нажмите «Редактировать»

Рядом с нужным токеном нажмите «Редактировать».

3

Выберите группу токенов

При желании дайте токену понятное название. В поле «Группа токенов» выберите подходящую группу.

Без выбранной группы ключ работать не будет — платформа выдаст ошибку.
💎

Подключение Gemini

1

Создайте подключение

В Tavo откройте API-подключения и нажмите Create. В поле Name укажите любое удобное название.

2

Заполните настройки Gemini

Model Platform Custom (Gemini Protocol)
API Base URL https://api.linkapi.ai/
API Key Ваш ключ из «Управления токенами»
Model Название модели, например gemini-3-pro-preview

После заполнения нажмите Save.

Для Gemini в этом подключении адрес указан без v1. Название модели проверьте в списке моделей своей группы на сайте LinkAPI.
🟠

Подключение Claude

1

Создайте отдельное подключение

В API-подключениях нажмите Create и укажите название в поле Name.

2

Заполните настройки Claude

Model Platform Custom (OpenAI Protocol)
API Base URL https://api.linkapi.ai/v1
API Key Ваш ключ из «Управления токенами»
Model Название модели, например claude-opus-4-6

После заполнения нажмите Save.

Для Claude используется OpenAI Protocol, а в конце адреса нужен /v1. Модель должна быть доступна в группе выбранного API-ключа.
